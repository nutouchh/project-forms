# Заявки на учебные проекты

Практическая работа №2: простое веб-приложение на Python, Flask и SQLite.

## Функции

- Форма: ФИО, группа, название проекта, описание.
- Два выпадающих списка: категория и приоритет.
- Список заявок, просмотр, редактирование и удаление.
- Проверка обязательных полей и допустимых значений списков.
- Хранение данных в SQLite; таблица создаётся при запуске.

## Запуск в Windows

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Открыть http://127.0.0.1:5000. Остановка сервера: Ctrl+C.
При повторном запуске достаточно последней команды.
В PyCharm выбрать интерпретатор .venv\Scripts\python.exe.

Локальные данные находятся в applications.db и не входят в Git.
Чтобы проверить сохранение, создайте заявку и перезапустите сервер.
Приложение рассчитано на локальную учебную демонстрацию.

## Проверка вручную

1. Открыть пустой список.
2. Создать две заявки, заполнив все шесть полей.
3. Открыть одну заявку: все значения должны совпасть с введёнными.
4. Изменить название, категорию и приоритет; сохранить.
5. Отклонить подтверждение удаления: запись остаётся.
6. Подтвердить удаление: запись исчезает.
7. Попробовать сохранить пустую форму: браузер не пропускает.
8. Перезапустить сервер: оставшаяся заявка сохраняется.
9. Открыть /applications/999999: сервер возвращает 404.
